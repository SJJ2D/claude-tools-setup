# claude-tools-setup

سكربت واحد يركّب أدواتي ومهاراتي في أي جلسة Claude Code سحابية جديدة (لينكس).

## الاستخدام
```bash
git clone https://github.com/SJJ2D/claude-tools-setup && cd claude-tools-setup
bash install-all.sh /مسار/B_Studio.zip
```

## ما الذي يركّبه
- **B Studio** (المهارتان `edit-studio` و`video-edit`) من ملف الـzip الذي تحتفظ به أنت.
- **12 مهارة OpenSEO** من مستودعها الرسمي (MIT).
- **VoiceStudio**: استنساخ الصوت محلياً على CPU (AGPL).
- **بيئة المونتاج**: بايثون 3.12 مع faster-whisper وmediapipe.

- **حقيبة المعلم** (`teacher-toolkit/`): مهارات للتخطيط والتقويم والدمج والتصميم والمواقع والألعاب. التفاصيل في `teacher-toolkit/CATALOG.md`.

## مهم
**لا ترفع ملف B Studio ولا مجلداته إلى هذا المستودع.** رخصته تمنع نشره أو رفعه في أي مكان حتى لو كان المستودع خاصاً؛ احتفظ بالـzip عندك وحده.

## ملاحظات الجلسات (اكتبها هنا وأنا أقرؤها في أول كل جلسة)
- التعليق الصوتي لمشروع «الغوّاص الصغير» مولَّد بصوت المستخدم المستنسخ على ElevenLabs (صوت T.Sajjad).
- الشعبة 1، الرقم الأكاديمي 202102571، الفصل الأول 2026/2027.
- عرض الجامعة: 5 شرائح كحد أقصى حسب معايير التكليف.
