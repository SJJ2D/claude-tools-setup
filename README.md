# claude-tools-setup

مستودع أدواتي ومهاراتي: سكربت واحد يركّب كل شي في أي جلسة Claude Code جديدة (لينكس).

## الاستخدام
```bash
git clone https://github.com/SJJ2D/claude-tools-setup && cd claude-tools-setup
bash install-all.sh
```
ثم ابدأ محادثة جديدة لتظهر المهارات.

## ما الذي يركّبه
| الجزء | المحتوى |
|---|---|
| **B Studio** | مهارتا `edit-studio` و`video-edit` من الملف `B Studio.zip` الموجود هنا (وإلا من المستودع الرسمي). |
| **بيئة المونتاج** | بايثون 3.12 مع faster-whisper وmediapipe. |
| **VoiceStudio** | استنساخ الصوت محلياً على CPU (AGPL). |
| **حقيبة المعلم** | تخطيط وتقويم ودمج (UDL)، شرائح، ألعاب تعليمية، فيديو شرح ومونتاج، مهارات Anthropic للمستندات والتصميم. |
| **حقيبة البرمجة والتصميم** | منهجية تطوير (superpowers)، Python/JS/APIs/قواعد بيانات/أمان، واجهات عربية RTL، أنظمة تصميم وإتاحة. |
| **design-toolkit + مهارات 21st.dev** | مهارة `design-toolkit` (GSAP وLenis وReact Bits وإرشادات 21st.dev، مع نسخ محلية من المكتبات) من مجلد `skills/`، ومهارات 21st.dev الرسمية الثمانية (بناء الواجهات واستكشافها ومراجعتها والبحث والتوليد والنشر). |
| **OpenSEO** | 12 مهارة SEO (تحتاج مفتاح DataForSEO). |

الفهرس الكامل بالمصادر والرخص: [`teacher-toolkit/CATALOG.md`](teacher-toolkit/CATALOG.md).

## ملاحظات
- لا يُنسخ كود أي مصدر خارجي داخل المستودع؛ السكربتات تنزّله من مصدره الرسمي على نسخة محددة (commit) تمت مراجعتها.
- مهارات حسابك على Claude (مثل docx وpdf وpptx وxlsx وغيرها) تأتي مع حسابك تلقائياً في كل جلسة ولا تحتاج تركيباً.
- ذاكرة المحادثات لا تنتقل بين الجلسات. أضف تحت أي ملاحظات تبي أتذكرها وأقرؤها في أول كل جلسة.
