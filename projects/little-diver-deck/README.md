# الغوّاص الصغير: عرض 5 سلايدات (TCHL418، التقييم 3)
النسخة المبسّطة (خط أكبر، عبارات قصيرة، نفس العناصر الستة المطلوبة).
البناء: `python3 build6.py && node render.js slides6.html out6_hd --pdf slides6.pdf --scale 2` ثم صورة لكل سلايد في PPTX (python-pptx) مع الملاحظات.
درس: السلايدات للعرض = عبارة قصيرة في سطر، نص 26px+ على لوحة 1920×1080، والتفاصيل تبقى في الخطة المكتوبة.
