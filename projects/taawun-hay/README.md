# جولة في حيّ التعاون – النسخة المطوّرة (درس التعاون، ثالث ابتدائي)

الملفان `hay/index.html` و`hay/world.js` يستبدلان نظيريهما في `taawun/hay/` بمستودع sunaina360 (بقية الملفات: vendor وfonts كما هي).

## ما تغيّر
- شاشة بداية: درس التعاون / إعداد طلاب الدكتور مهند مصطفى / صف ثالث ابتدائي — فرقة ١ / انقر للبدء (الشاشة كلها قابلة للنقر).
- المواقف الستة الجديدة (3 تعاونية + 3 غير تعاونية) مجسّمة ومتحركة، موزّعة بالتناوب حتى لا يخمّن التلميذ بالنمط.
- كل موقف خطوتان: الحكم (تعاوني؟) ثم اختيار السبب الصحيح من ثلاثة، فيقل التخمين ويظهر التفكير.
- ظهور القصة كاملة في اللوحة، وأسماء الشخصيات فوق رؤوسهم، وإزاحة الكاميرا كي لا تحجب اللوحة المشهد.
- الأصوات كانت معطّلة فعليًا (audio() لا تُستدعى و tone() تعود فورًا): فُعّلت مع زر كتم 🔊. القراءة الصوتية (say) بقيت معطّلة كما في الأصل.
- العلامات الثلاث ثابتة في الأعلى، وشاشة ختام: نجوم + ملخّص المواقف + «العب من جديد».
