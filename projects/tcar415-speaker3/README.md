# TCAR415، العرض السادس: شرائح المتحدث الثالث (المحور د)
العوامل الاجتماعية الباعثة على التغير، من كتاب الأحمري (2022) «لغويات اجتماعية»، ص 69–71، 77، 79–80، 174–175. الكتاب نفسه لا يُرفع.
- `content.py`: نص الشرائح وملاحظات الإلقاء، و`build.py`: القالب (Noto Kufi وNoto Naskh، ولون المحور #c05621 مستوحى من ملف توزيع المتحدث الرابع).
- البناء: `python3 build.py && node render.js slides.html hd --pdf Speaker3_Axis_D.pdf --scale 2 && python3 make_pptx.py Speaker3_Axis_D.pptx`
- بطاقة المحاورة: `python3 card.py` ثم طباعة card.html إلى PDF (A4) بـ playwright.
- مرّ بأربع مراجعات مستقلة (مطابقة المصدر، والروبرك، واللغة، والتخصص)، ثم فحص أخير (الشكل، والروبرك، واللغة مع المطابقة).
